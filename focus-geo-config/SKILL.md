# FocusGEO实操配置指南

## 任务目标
- 本Skill用于：通过结构化对话引导用户完成FocusGEO系统的完整配置流程
- 能力包含：6阶段深度对话引导、策略制定、内容规划、配置手册生成
- 触发条件：用户提到"启动FocusGEO配置"、"GEO系统实施"、"内容生成策略配置"或类似需求

## 前置准备
- 准备企业基本信息：品牌名称、行业领域、核心业务、目标用户群体
- 准备现有资源：品牌资料库、已有内容资产、目标平台清单
- 无需外部依赖，所有配置通过对话完成

## 操作步骤

### 标准流程：6阶段配置

#### 阶段1：企业画像深度对话
**目标**：建立完整的企业画像，为后续配置提供基础

**执行要点**：
1. 通过分层对话收集以下信息：
   - 基础信息：企业名称、行业、规模、业务模式
   - 品牌定位：品牌调性、核心价值、差异化优势
   - 目标用户：用户画像、需求场景、决策路径
   - 业务目标：GEO期望效果、关键指标、时间周期
2. 对话引导技巧：
   - 从宏观到微观：先了解整体业务，再深入细节
   - 追问关键点：对模糊表述要求具体化（如"提升品牌影响力"→"具体哪个维度、如何量化"）
   - 验证一致性：确保各维度信息不冲突
3. 输出结构化企业画像

**输入要求**：
- 企业基础信息（必需）
- 目标用户描述（必需）
- 业务目标说明（必需）

**输出成果**：结构化企业画像文档

**验证清单**：
- [ ] 品牌定位清晰（不超过3个核心价值）
- [ ] 目标用户画像具体（包含3-5个关键特征）
- [ ] 业务目标可量化（包含明确的KPI指标）
- [ ] 差异化优势明确（2-3个独特卖点）

**参考资源**：见 [references/enterprise-profile-template.md](references/enterprise-profile-template.md)（模板结构）

---

#### 阶段2：关键词策略制定
**目标**：建立完整的关键词体系，支撑内容生成和搜索优化

**执行要点**：
1. 基于企业画像识别关键词方向：
   - 品类词：行业、产品、服务相关
   - 问题词：用户痛点、需求场景
   - 意向词：购买、咨询、学习等搜索意图
   - 竞品词：行业竞品、替代方案
2. 关键词分类与优先级：
   - 核心词：高搜索量+强相关（10-20个）
   - 长尾词：低搜索量+精准转化（50-100个）
   - 否定词：需排除的不相关词
3. 搜索意图匹配：
   - 信息类意图（how/what/why）
   - 交易类意图（buy/best/price）
   - 导航类意图（品牌名/官网）

**输入要求**：
- 企业画像（来自阶段1）
- 行业关键词清单（如有）
- 竞品分析信息（如有）

**输出成果**：分层关键词清单及策略说明

**验证清单**：
- [ ] 核心关键词10-20个，覆盖主要业务
- [ ] 长尾关键词50-100个，覆盖具体场景
- [ ] 每个关键词标注搜索意图
- [ ] 优先级分级明确（高/中/低）
- [ ] 否定词清单完整

**参考资源**：见 [references/keyword-strategy-guide.md](references/keyword-strategy-guide.md)（分类方法与示例）

---

#### 阶段3：知识库规划
**目标**：设计知识库结构，确保内容覆盖全面且逻辑连贯

**执行要点**：
1. 知识库主题规划：
   - 基于关键词提取主题簇（每个核心词对应一个主题）
   - 确定主题层级（一级主题→二级主题→内容点）
   - 规划内容类型（教程、案例、问答、对比等）
2. 内容优先级规划：
   - 必建内容：直接服务核心业务的关键词
   - 选建内容：长尾需求相关
   - 暂缓内容：低频或边缘场景
3. 知识库更新策略：
   - 初始内容清单（前30天）
   - 迭代更新频率（如每月新增X篇）
   - 内容优化机制（数据驱动更新）

**输入要求**：
- 企业画像（阶段1）
- 关键词策略（阶段2）

**输出成果**：知识库结构树 + 内容优先级清单

**验证清单**：
- [ ] 一级主题3-8个，覆盖核心业务
- [ ] 每个一级主题包含2-5个二级主题
- [ ] 内容类型分布合理（至少3种类型）
- [ ] 优先级分级明确（P0/P1/P2）
- [ ] 更新策略可执行（有明确数量和时间）

**参考资源**：见 [references/knowledge-base-planning.md](references/knowledge-base-planning.md)（结构规范与示例）

---

#### 阶段4：GEO提示词设计
**目标**：设计高质量的内容生成提示词，确保输出符合品牌和业务需求

**执行要点**：
1. 提示词基础架构：
   - 角色设定（如"你是行业专家"）
   - 任务描述（明确输出内容类型和目标）
   - 上下文信息（企业画像、关键词、目标用户）
   - 约束条件（字数、风格、结构要求）
   - 输出格式（标题、正文、标签等）
2. 品牌一致性控制：
   - 语调规范（专业/亲切/严谨等）
   - 用词禁忌（避免的表达）
   - 品牌植入方式（自然提及而非生硬广告）
3. 质量控制标准：
   - 原创性要求（避免抄袭、重复）
   - 准确性要求（事实核查、数据来源）
   - 实用性要求（可操作、有价值）

**输入要求**：
- 知识库规划（阶段3）
- 品牌调性规范（来自阶段1）
- 内容类型需求

**输出成果**：分类型提示词模板库

**验证清单**：
- [ ] 每种内容类型有对应提示词模板
- [ ] 提示词包含完整的5大要素（角色/任务/上下文/约束/格式）
- [ ] 品牌语调要求清晰
- [ ] 质量控制标准可衡量
- [ ] 提供至少3个完整示例

**参考资源**：见 [references/geo-prompt-design.md](references/geo-prompt-design.md)（模板与示例）

---

#### 阶段5：多平台改编策略
**目标**：制定各平台内容适配方案，优化分发效果

**执行要点**：
1. 平台特性分析：
   - 平台用户画像（年龄、兴趣、行为习惯）
   - 内容偏好（形式、长度、风格）
   - 算法机制（推荐逻辑、权重因素）
2. 内容改编策略：
   - 形式适配（图文/视频/短内容等）
   - 结构调整（开头/主体/结尾优化）
   - 关键词植入（符合平台搜索习惯）
3. 分发矩阵规划：
   - 核心平台：重点投入（2-3个）
   - 辅助平台：次优投入（3-5个）
   - 监测平台：观察测试（1-2个）
4. 时间节奏安排：
   - 发布频率（各平台不同）
   - 发布时段（根据用户活跃时间）
   - 内容复用策略（一源多改）

**输入要求**：
- GEO提示词（阶段4）
- 目标平台清单
- 各平台基础信息

**输出成果**：各平台适配方案 + 分发计划

**验证清单**：
- [ ] 至少覆盖5个主流平台
- [ ] 每个平台有明确的改编策略
- [ ] 分发优先级清晰（核心/辅助/监测）
- [ ] 发布频率和时间具体可执行
- [ ] 内容复用策略合理（避免过度重复）

**参考资源**：见 [references/platform-adaptation-guide.md](references/platform-adaptation-guide.md)（平台特性与改编示例）

#### 阶段6：配置手册生成
**目标**：整合前5阶段成果，生成完整的《FocusGEO实操配置手册》

**执行要点**：
1. 手册结构规划：
   - 执行摘要（项目背景、目标、范围）
   - 企业画像（阶段1成果）
   - 关键词策略（阶段2成果）
   - 知识库规划（阶段3成果）
   - GEO提示词库（阶段4成果）
   - 平台改编方案（阶段5成果）
   - 实施路线图（时间表、里程碑、责任人）
   - 附录（术语表、工具清单、联系方式）
2. 内容整合规范：
   - 保持各阶段成果的完整性
   - 添加必要的衔接说明
   - 确保格式统一、逻辑连贯
3. 可执行性增强：
   - 添加检查清单（每个阶段的关键任务）
   - 提供示例模板（可复用的文档模板）
   - 标注关键节点（决策点、审核点）

**输入要求**：
- 前5阶段所有输出成果
- 项目时间要求（如有）

**输出成果**：完整的《FocusGEO实操配置手册》

**验证清单**：
- [ ] 包含所有6个阶段的成果
- [ ] 结构完整，章节清晰
- [ ] 实施路线图可执行（有明确时间和责任人）
- [ ] 提供必要的检查清单和模板
- [ ] 无冗余信息，重点突出

**参考资源**：见 [references/manual-generation-template.md](references/manual-generation-template.md)（手册结构与模板）

### 流程控制要点

**阶段衔接**：
- 每个阶段完成后，输出成果需经用户确认
- 发现问题时可返回上一阶段调整
- 所有阶段按顺序执行，避免跳过

**对话策略**：
- 主动式提问：当信息不足时主动引导
- 验证式确认：对关键信息要求用户确认
- 迭代式优化：根据反馈持续完善

**质量保障**：
- 每个阶段提供验证清单
- 关键节点要求用户确认
- 最终手册需经完整性检查

## 使用示例

### 示例1：B2B软件公司GEO配置

**场景/输入**：
- 企业：CRM系统服务商，服务中小企业
- 目标：通过内容营销提升搜索可见度，获取潜在客户
- 当前问题：缺乏系统化内容策略

**预期产出**：
- 完整的《FocusGEO实操配置手册》，包含：
  - 企业画像（聚焦中小企业CRM痛点）
  - 关键词策略（如"中小企业CRM选择"、"CRM系统对比"等）
  - 知识库规划（产品教程、行业案例、实施指南等主题）
  - GEO提示词模板（教程类、案例类、问答类）
  - 平台改编方案（知乎深度内容、公众号案例、短视频演示）
  - 3个月实施路线图

**关键要点**：
- B2B企业需突出专业性和解决方案价值
- 关键词聚焦用户决策链条（从认知到选择）
- 知识库优先覆盖高频问题（如选型、实施、使用）

### 示例2：本地生活服务商家GEO配置

**场景/输入**：
- 企业：高端健身房，服务城市白领
- 目标：提升本地搜索排名，吸引到店体验
- 当前问题：线上曝光不足，难以触达目标用户

**预期产出**：
- 本地化GEO配置手册，包含：
  - 企业画像（高端健身、城市白领、健康生活方式）
  - 关键词策略（本地化关键词如"XX区健身房"、"私教课程"）
  - 知识库规划（健身教程、营养指南、会员故事）
  - GEO提示词模板（体验类、科普类、促销类）
  - 平台改编方案（抖音健身视频、大众点评图文、小红书种草）
  - 1个月快速启动计划

**关键要点**：
- 本地化关键词必须包含地域标识
- 内容突出体验和服务质量
- 平台选择需匹配目标用户习惯（抖音、大众点评、小红书）

### 示例3：教育培训机构GEO配置

**场景/输入**：
- 企业：K12在线教育机构，提供全科辅导
- 目标：建立权威内容形象，获取家长信任
- 当前问题：内容同质化严重，缺乏差异化

**预期产出**：
- 教育行业GEO配置手册，包含：
  - 企业画像（K12全科、优质师资、个性化辅导）
  - 关键词策略（学科关键词+年级关键词+问题词）
  - 知识库规划（学科知识点、学习方法、升学指导）
  - GEO提示词模板（知识点讲解、学习方法、家长指南）
  - 平台改编方案（公众号深度文章、短视频知识点、社群答疑）
  - 6个月长期内容建设计划

**关键要点**：
- 关键词需覆盖全学科全年级
- 内容需兼顾权威性和易读性
- 多平台联动：公众号做深度、短视频做传播、社群做服务
