# GEO内容生成提示词设计模板

## 概览
本文档提供GEO内容生成提示词的系统设计方法，包括提示词架构、模板库、质量控制标准等。

## 核心内容

### 1. 提示词基础架构

#### 1.1 标准提示词结构
```
[角色设定]
你是一位[角色身份]，具备[专业背景]和[经验年限]。

[任务描述]
请为[目标受众]撰写一篇[内容类型]，主题是[核心主题]。

[上下文信息]
- 企业背景：[企业名称]、[行业领域]、[核心价值]
- 目标用户：[用户画像]、[需求场景]、[痛点]
- 关键词：[核心关键词]、[长尾关键词]
- 品牌调性：[语调风格]、[用词规范]

[约束条件]
- 字数：[具体范围]字
- 结构：[标题/引言/正文/结尾]
- 风格：[专业/亲切/严谨/活泼]
- 品牌植入：[自然提及/软性植入]
- 格式要求：[小标题/列表/加粗等]

[输出格式]
标题：[要求]
正文：[要求]
标签：[关键词标签]
摘要：[字数要求]
```

#### 1.2 提示词要素说明
**角色设定（Role）**：
- 作用：明确输出视角和专业度
- 示例：行业专家、资深顾问、产品经理、用户代表
- 设计原则：与内容主题和受众匹配

**任务描述（Task）**：
- 作用：明确输出内容和目标
- 示例：撰写教程、编写指南、分析案例
- 设计原则：具体、可衡量、可达成

**上下文信息（Context）**：
- 作用：提供背景信息，确保内容相关
- 包含：企业背景、目标用户、关键词、品牌调性
- 设计原则：聚焦关键信息，避免冗余

**约束条件（Constraints）**：
- 作用：控制输出质量和风格
- 包含：字数、结构、风格、品牌植入、格式
- 设计原则：明确、可验证

**输出格式（Output Format）**：
- 作用：规范输出结构
- 包含：标题、正文、标签、摘要
- 设计原则：符合平台要求和用户习惯

### 3. 品牌一致性控制

#### 3.1 语调规范
**专业型**：
- 适用场景：B2B企业、技术产品、专业服务
- 用词特点：准确、严谨、客观
- 避免表达：夸张、情绪化、网络用语

**亲切型**：
- 适用场景：B2C企业、消费品、教育培训
- 用词特点：温暖、友好、易懂
- 避免表达：冷漠、疏离、过于专业

**活泼型**：
- 适用场景：年轻品牌、创意产品、娱乐内容
- 用词特点：生动、有趣、有个性
- 避免表达：刻板、死板、缺乏感染力

**严谨型**：
- 适用场景：金融、医疗、法律等专业领域
- 用词特点：精确、权威、可信
- 避免表达：模糊、不确定、主观臆断

#### 3.2 用词禁忌
**通用禁忌**：
- 绝对化表达：最好、最、唯一、第一
- 虚假承诺：保证、一定、必定
- 夸大宣传：神奇、革命性、颠覆性
- 低俗表达：网络热词、低俗段子

**品牌特定禁忌**：
根据企业品牌手册，列出需要避免的用词和表达方式。

#### 3.3 品牌植入原则
**自然植入**：
- 在合适场景下提及产品功能
- 避免生硬广告
- 保持内容价值优先

**软性植入**：
- 以案例方式呈现产品优势
- 通过对比突出产品价值
- 在解决问题时推荐产品

**比例控制**：
- 品牌植入内容占比≤20%
- 核心价值内容占比≥80%
- 保持内容客观性

### 4. 质量控制标准

#### 4.1 原创性要求
**原创性定义**：
- 内容未在其他平台发布
- 非抄袭、非洗稿
- 提供独特观点或价值

**验证方法**：
- 检查内容与现有内容的重合度
- 确保提供独特视角或案例
- 引用他人观点需注明来源

#### 4.2 准确性要求
**事实核查**：
- 数据来源可靠
- 案例真实可信
- 技术细节准确

**验证方法**：
- 核实数据来源
- 确认案例真实性
- 请专业人士审核技术内容

#### 4.3 实用性要求
**可操作性**：
- 提供具体步骤和方法
- 避免空泛理论
- 给出可落地的建议

**验证方法**：
- 检查是否提供具体步骤
- 确保方法可实施
- 用户反馈是否有帮助
