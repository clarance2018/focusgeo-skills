# FocusGEO Config — FocusGEO 系统全流程配置向导

> 通过 6 阶段深度对话，引导用户完成企业画像、关键词策略、知识库规划、GEO 提示词设计及多平台改编，最终产出可直接执行的《FocusGEO实操配置手册》。

## 技能信息

| 属性 | 内容 |
|------|------|
| **名称** | `focus-geo-config` |
| **触发场景** | 用户需要实施 FocusGEO 系统、制定 GEO 内容策略或生成配置文档时 |
| **输出成果** | 《FocusGEO实操配置手册》（可直接落地执行） |
| **核心方法论** | GEO（生成式引擎优化）|

## 什么是 GEO？

**GEO = Generative Engine Optimization = AI 搜索推荐优化**

传统 SEO 是"让搜索引擎找到你"，GEO 是**让 DeepSeek、豆包、文心一言、通义千问、腾讯元宝等 AI 大模型在回答中主动推荐你的品牌**。

## 各阶段核心产出

### 阶段 1：企业画像配置
- 基础信息表（公司名称、规模、行业、地区、官网）
- 产品描述 + 产品优势列表
- 品牌故事 + 信任背书 + 品牌调性 + 用户痛点

### 阶段 2：关键词策略制定
- 3-5 个核心关键词（完整问题形式）
- 50-100 个长尾关键词
- 否定词清单
- 搜索意图分类（信息类 / 交易类 / 导航类）

### 阶段 3：知识库规划
- 知识库结构树（一级主题 → 二级主题 → 内容点）
- 内容优先级清单（P0/P1/P2）
- 更新策略与迭代节奏

### 阶段 4：GEO 提示词设计
- 分内容类型的提示词模板（问答 / 对比 / 测评 / 推荐）
- 品牌语调规范
- 质量控制标准

### 阶段 5：多平台改编策略
- 目标平台清单与优先级
- 各平台改编提示词
- 分发矩阵与发布节奏

### 阶段 6：配置手册生成
- 《FocusGEO实操配置手册》完整文档
- 48 小时行动清单
- 实施路线图与里程碑

## 适用场景

- ✅ 初次实施 FocusGEO 系统，需要从零配置
- ✅ 制定 GEO 内容策略，建立系统化内容体系
- ✅ 已有 FocusGEO 系统，需要优化配置参数
- ✅ 团队交接，需要标准化的配置文档
